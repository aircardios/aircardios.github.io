macOS 提示“无法打开 AirCard，因为无法验证开发者”解决教程 (Gatekeeper 解除)

在 Mac 电脑安装 AirCard.dmg 提示应用已损坏或无法验证开发者身份？本文提供访达右键打开及终端一条命令彻底解除 Gatekeeper 隔离属性的方法。

⚠️ 故障现象 (Symptom)

将 AirCard.app 拖入“应用程序”文件夹后双击打开，系统弹窗提示“无法打开 AirCard，因为无法验证开发者”或“AirCard 已损坏，您应该将它移到废纸篓”。

💡 根本原因 (Root Cause)

macOS Gatekeeper 安全防线对未购买苹果高昂企业证书签名的开源自由软件默认施加了 com.apple.quarantine（隔离拓展属性）保护。

🔧 彻底解决排查步骤

✓ 方法一：访达右键打开（最简单）

打开访达（Finder）中的“应用程序”，按住键盘 Control 键并右键点击 AirCard.app，在右键菜单中点击“打开”，在弹出的提示框中点击“仍要打开”即可。

✓ 方法二：终端一行命令永久解除隔离（最彻底）

按下 Command + 空格打开聚焦搜索，输入“终端 (Terminal)”回车。粘贴以下命令并回车，输入锁屏开机密码即可永久解除限制： sudo xattr -cr /Applications/AirCard.app

❓ 相关追问解答

Q: 执行 sudo 命令输入密码时为什么屏幕没反应？

macOS 终端输入密码时为了安全不会显示星号或光标移动，盲打输入你的电脑锁屏密码后直接按回车即可。

Q: Apple Silicon M系列与 Intel 机型通用吗？

通用。官网提供的是 Universal 2 双架构 DMG 安装包，原生适配 M1/M2/M3/M4 系列芯片与 Intel x86_64 Mac。
