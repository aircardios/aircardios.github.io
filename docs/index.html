AirCard-iOS 📱 (iPhone 独立运行)

最新版 v1.3

脱离电脑限制！原生完成卡面替换、锁屏按键注入与 PosterBoard 壁纸定制，集成 NeoSpring 免重启生效。

⚡ 前往 iOS 下载中心

📌 侧载安装与前置配置要求：

1
侧载安装 IPA
使用 TrollStore (巨魔)、SideStore、AltStore、LiveContainer 或爱思助手将 AirCard-iOS.ipa 签名安装到手机中。
2
启用 LocalDevVPN
打开 LocalDevVPN 开启回环路由（127.0.0.1 或 10.7.0.1），确保本地应用能够连通内部系统服务。
3
设备自身配对
打开系统“设置 ➔ 隐私与安全性 ➔ 开发者模式 ➔ 与 AirCard-iOS 配对”（Bonjour 自动广播免电脑自配对）。
4
一键应用与注销
在 App 中导入卡面、 .passthm 或 .tendies，点击应用，通过 NeoSpring 自动注销即可立即生效！
💡
提示：iOS 原生端利用 Bonjour 本地广播与 AirTraffic 协议。如遇到配对不成功，请检查 LocalDevVPN 状态是否保持开启，并在开发者模式中重新确认配对。

AirCard for macOS 🍎 (Universal DMG)

最新版 v1.2.2

原生适配 Apple Silicon (M1/M2/M3/M4) 与 Intel x86 芯片，无需配置终端环境，即拖即用。

⚡ 前往 macOS 下载中心

📌 macOS 操作步骤：

1
拖拽安装 App
双击打开 AirCard.dmg，将 AirCard.app 拖入“应用程序 (Applications)”文件夹。
2
连接并信任 iPhone
通过 USB 数据线将 iPhone 连接至 Mac，解锁 iPhone 并在弹出的提示中点击“信任此电脑”。
3
双击电源键识卡
点击 Scan Cards，在 iPhone 上双击电源键调出 Apple Pay，轻触卡片即可秒级自动捕获卡片哈希。
4
写入并重启生效
选图后点击 Flash Skins。在手机多任务后台划掉钱包 App（或重启手机）即可看到新卡面！
macOS 首次打开提示“无法验证开发者”或“已损坏”？
方式一：在“访达 ➔ 应用程序”中找到 AirCard.app，右键点击 ➔ 按住 Option 键点击“打开”。
方式二：打开终端执行命令解除限制：
sudo xattr -cr /Applications/AirCard.app

📌 Windows 操作步骤与系统要求：

1
前置 Apple 驱动
确保电脑已安装 64 位 iTunes 或 Apple 移动设备支持服务 (AMDS) 以识别 USB 通信。
2
连接手机并运行
用数据线连接 iPhone，解锁并点击“信任”，直接双击运行 aircard.exe，无需任何安装过程。
3
捕获哈希与选图
在 Wallet 页面点击 Scan，手机打开钱包触碰卡片。点击 Choose Image 选择任意图片（自动裁切为 1536×969）。
4
写入与后台刷新
点击 Apply Card Skin。手机多任务上滑退出钱包 App，重新进入即可见证全新卡面！
🔧 iPhone 无法识别、AirTraffic 同步卡住或报错？（驱动修复指南）
Windows 系统下苹果 USB 驱动冲突是首要原因：
  1. 下载并安装 3uTools (爱思助手)。
  2. 拔下 iPhone 数据线。
  3. 在 3uTools 中点击 “工具箱 (Toolbox) ➔ 修复驱动 (Repair Driver)”。
  4. 点击 “立即修复” 并等待驱动重装完成。
  5. 重新插上 iPhone，信任电脑，重新启动 AirCard 即可完美识别！
🚨 特别注意：锁屏按键主题生效必须关闭“粗体文本”！
在 iPhone 上前往 “设置 ➔ 显示与亮度”，确保 “粗体文本 (Bold Text)” 保持关闭。若开启了粗体文本，iOS 会强制渲染系统矢量字体而忽略按键主题缓存。

💳 如何自定义 Apple 钱包卡面？

第一步：连接与识别

无论使用电脑端还是 iOS 原生端，开启卡面扫描（Scan Cards），在 iPhone 上轻触或双击电源键展示对应卡片，程序会自动捕捉其独一无二的 Pass Hash。

第二步：选择图片与写入

点击卡片 Mockup 或拖入你喜欢的图片（动漫、赛博朋克、奢华黑金或银行定制 Logo）。程序会自动完成高精度居中裁剪与多级分辨率缓存生成。

第三步：刷新生效

点击 Flash / Apply 按钮。写入成功后，从屏幕底部上滑呼出多任务，彻底关闭钱包 (Wallet) App，重新打开即可享受新卡面！

🔢 如何应用锁屏按键主题 (.passthm)？

第一步：获取主题包

下载任意 .passthm 主题文件（可在下方网盘下载整理好的精选合集包）。

第二步：导入与版本选择

将 .passthm 文件拖入 AirCard。选择目标系统缓存版本（iOS 18+ 默认选择 Auto / TelephonyUI-10）。

第三步：应用与重启

点击 Apply Passcode Theme 写入缓存。写入完成后，重启你的 iPhone（或注销锁屏）以加载全新锁屏按键图标！

FAQ

常见问题与排障指南

遇到疑问或异常？这里为你整理了高频问题的排查方案。

❓ 使用 AirCard 会导致封号或影响 Apple Pay 支付吗？

不会。AirCard 仅仅替换了 iOS 本地系统缓存中的卡面展示图片（cardBackgroundCombined@3x.png 等）以及拨号盘图形缓存，并没有触碰底层 Secure Enclave 安全芯片或篡改银行卡实际凭据。Apple Pay 的刷卡支付和安全验证完全不受任何影响。

❓ 为什么写入锁屏按键主题后，屏幕依然显示系统默认字体？

最常见的原因是开启了系统“粗体文本”。请打开 iPhone 的“设置 ➔ 显示与亮度”，务必将“粗体文本 (Bold Text)”关闭。开启粗体后，iOS 会跳过图形缓存直接由系统渲染矢量字形。

❓ Windows 提示设备未连接或 AirTraffic 同步失败？

这是 Windows 环境下最常见的问题，由于苹果驱动被篡改或损坏。请安装 3uTools (爱思助手)，拔出数据线，点击“工具箱 ➔ 修复驱动 ➔ 立即修复”，修复完成后重新插入手机信任即可。

❓ macOS 提示“无法打开 AirCard，因为无法验证开发者”？

这是 macOS Gatekeeper 安全机制。请在访达中右键点击 AirCard.app ➔ 选择“打开”；或在终端中运行 sudo xattr -cr /Applications/AirCard.app 即可永久解除拦截。

❓ AirCard-iOS 手机端提示配对失败或无法连接回环？

请确认已在后台保持开启 LocalDevVPN，回环地址指向 127.0.0.1 或 10.7.0.1。接着前往“设置 ➔ 隐私与安全性 ➔ 开发者模式”，点击“与 AirCard-iOS 配对”确认授权。

❓ 如何恢复回原来的默认卡面和锁屏按键？

AirCard 内置 Books 快照还原机制。在 App 中点击“Restore / 还原默认”，或者在系统钱包中移除卡片后重新添加，即可一键恢复苹果官方原始外观。
