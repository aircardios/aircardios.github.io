Apple 钱包 (Apple Pay) 卡面定制实战

突破 Apple Pay 卡面限制，为银行卡、交通卡（Suica、八达通、全国一卡通）赋予个性化视觉

🛡️

为什么免越狱且绝对安全？

AirCard 仅通过苹果原生的 AirTraffic 同步通道替换系统本地缓存中的卡面展示图片（cardBackgroundCombined@3x.png 等）。绝不触碰 Secure Enclave 安全芯片，不改变卡号及凭据，Apple Pay 刷卡消费完全不受影响！

推荐分辨率: 1536 × 969 px
第一步 📡

连接与扫卡识别

打开 AirCard（iOS 原生端确保已连接回环，电脑端连接数据线信任手机），点击 Scan Cards (扫描卡片)。在 iPhone 上双击电源键打开 Apple Pay 页面，轻触目标卡片，程序将秒级抓取独一无二的 Pass Hash。

💡 提示：若有多张卡片，依次轻触切换即可全量识别。
第二步 🎨

选择卡面并微调

点击卡片预览框，或直接拖拽你喜爱的图片至窗口。AirCard 内置智能居中算法，会自动将图像缩放裁切为标准 1536×969 比例，同时生成 Retina @2x 与 @3x 对应层级的高清纹理。

💡 提示：支持 PNG、JPG、WEBP 格式，黑金、赛博朋克或极简渐变效果最佳。
第三步 ⚡

写入缓存与刷新生效

点击 Flash Skins 或 Apply 按钮，等待进度条完成写入。写入成功后，从屏幕底部上滑呼出 iPhone 多任务后台，彻底向上划掉“钱包 (Wallet)”App，再次打开即可看到全新震撼卡面！

💡 提示：若卡面未立即刷新，重启一次手机即可清空旧显存。

锁屏数字密码按键主题 (.passthm) 教程

替换 iOS 18+ 默认灰底数字键盘，应用热门 Cowabunga / Nugget 格式锁屏按键皮肤

🚨

最高频避坑警示：锁屏按键主题生效必须关闭“粗体文本”！

99% 的用户反馈“写入成功但重启后仍是默认数字”均是因为开启了系统粗体。 请立即前往 iPhone “设置 ➔ 显示与亮度”，确保 “粗体文本 (Bold Text)” 处于【关闭】状态！ 开启粗体文本时，iOS 将强制跳过本地图形缓存而由系统矢量引擎重新绘制默认字形。

步骤一

获取 .passthm 主题文件

.passthm 是 iOS 社区通用的锁屏主题包格式。你可以从本站网盘的精选资源包下载、从 GitHub 社区获取，或通过切片工具自行制作。

步骤二

导入主题与版本选择

在 AirCard 客户端中将 .passthm 文件导入。在系统版本选项中，iOS 18+ 用户请保持默认选择 Auto / TelephonyUI-10（iOS 18/27 统一使用的拨号渲染层）。

步骤三

写入并重启 iPhone

点击 Apply Passcode Theme。提示 Success 写入完成后，必须完整重启你的 iPhone（长按电源键+音量键关机后再开机），开机点亮锁屏即可看到全新按键！

PosterBoard 锁屏壁纸定制 (.tendies) 实战 (v1.3 新增)

突破 iOS 沙盒限制，直接将 .tendies 壁纸归档包注入系统 PosterBoard 存储，免重启生效

步骤一

导入 .tendies 归档包

在 AirCard-iOS 中切换至 Tendies (壁纸) 页面，点击选择文件，直接从系统自带“文件”App 中选取任意 .tendies 格式的锁屏壁纸归档包。App 内置解压引擎将自动解析资源。

步骤二

智能容器匹配与注入

引擎自动检测当前设备上激活的 PosterBoard 壁纸描述符（Descriptor UUID）与存储容器，自动将壁纸资产与元数据精准注入系统壁纸沙盒目录。

步骤三

NeoSpring 免重启注销

写入完成后，内置 NeoSpring 模块将基于 WebKit GPU 进程崩溃机制自动触发轻量注销（Respring），**无需整机重启**即可让全新锁屏壁纸立刻展现在屏幕上！

macOS 与 Windows 电脑端配置与避坑

桌面端适合大批量图片预处理、海报精准无缝九宫格切片与高级主题微调

🍎 macOS (Universal 2 DMG)

M系列 + Intel 通用

1. 安装简单：打开下载的 AirCard.dmg，将 AirCard.app 拖入“应用程序”即可。

2. 连接手机：使用原装或 MFi 认证数据线连接 iPhone 至 Mac，在 iPhone 屏幕上点击“信任此电脑”并输入锁屏密码。

⚠️ Gatekeeper 拦截提示“无法验证开发者”？
在访达“应用程序”中右键点击 AirCard.app ➔ 选择“打开”；或在终端执行一行命令解除隔离：
sudo xattr -cr /Applications/AirCard.app

🪟 Windows (Rust 原生 EXE)

~7.5 MB 单文件免安装

1. 绿色便携：直接运行 aircard.exe，无任何臃肿依赖。

2. 前置驱动要求：Windows 需安装 64 位 iTunes 或 Apple 移动设备支持服务 (AMDS) 官方驱动通道。

🔧 提示“设备未连接 / 无法同步 AirTraffic”？
这是 Win 平台最常见的 Apple USB 驱动冲突。只需打开 爱思助手 (3uTools) ➔ 拔出手机 ➔ 点击“工具箱 ➔ 修复驱动 ➔ 立即修复”。修复后重新插入手机信任即可百分之百解决！

快照还原与一键恢复默认

随时无损复原官方原始外观，零风险放心体验

💳 如何恢复 Apple Pay 原始银行卡面？

  • 方式一 (App 内一键还原)：在 AirCard 客户端中，选中对应卡片，点击 Restore / 还原默认 按钮并写入，再彻底划掉钱包 App。
  • 方式二 (重新添加卡片)：在系统“钱包”中将卡片移除，重新绑定添加该卡，苹果官方服务器会自动重新下发原始发卡行卡面图片。

🔢 如何恢复系统默认锁屏数字按键？

  • 方式一 (清除按键主题)：在 AirCard 的 Passcode 页面中点击 Clear Theme / 清除缓存，完成后重启 iPhone。
  • 方式二 (开关粗体文本)：在“设置 ➔ 显示与亮度”中开启一次“粗体文本”再关闭，或直接重启手机，系统会自动重新生成默认拨号图标。

疑难排障与常见问答 (FAQ)

整理中文用户在实践过程中最高频的疑问与排障手段

❓ 为什么写入锁屏按键主题后，屏幕依然显示系统默认字体？

最常见的原因是开启了系统“粗体文本”。请打开 iPhone 的“设置 ➔ 显示与亮度”，务必将“粗体文本 (Bold Text)”关闭。开启粗体后，iOS 会跳过图形缓存直接由系统渲染矢量字形。

❓ 使用 AirCard 会导致封号或影响 Apple Pay 支付吗？

不会。AirCard 仅仅替换了 iOS 本地系统缓存中的卡面展示图片（cardBackgroundCombined@3x.png 等）以及拨号盘图形缓存，并没有触碰底层 Secure Enclave 安全芯片或篡改银行卡实际凭据。Apple Pay 的刷卡支付和安全验证完全不受任何影响。

❓ Windows 提示设备未连接或 AirTraffic 同步失败？

这是 Windows 环境下最常见的问题，由于苹果驱动被篡改或损坏。请安装 3uTools (爱思助手)，拔出数据线，点击“工具箱 ➔ 修复驱动 ➔ 立即修复”，修复完成后重新插入手机信任即可。

❓ AirCard-iOS 手机端提示配对失败或无法连接回环？

请确认已在后台保持开启 LocalDevVPN，回环地址指向 127.0.0.1 或 10.7.0.1。接着前往“设置 ➔ 隐私与安全性 ➔ 开发者模式”，点击“与 AirCard-iOS 配对”确认授权。
