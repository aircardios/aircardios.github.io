🚀 安装与配置流程

✓ 第一步：电脑打开爱思助手并连接手机

使用数据线连接 iPhone 至 Windows/Mac 电脑，手机屏幕点击“信任此电脑”并输入密码。

✓ 第二步：打开“IPA 签名”工具

进入爱思助手“工具箱 ➔ IPA 签名”，点击“添加 IPA”选取本站下载的 AirCard IPA 安装包。

✓ 第三步：添加 Apple ID 并开始签名

勾选“使用 Apple ID 签名”，添加你的 Apple 账号密码（建议使用备用 ID），点击“开始签名”。签名成功后点击“安装到设备”即可！

💡 避坑专享建议：安装后首次打开若提示“不受信任的开发者”，前往手机“设置 ➔ 通用 ➔ VPN与设备管理”点击信任你的账号即可。
